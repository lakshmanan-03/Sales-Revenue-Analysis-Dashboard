# Retail Sales & Profit Analysis Dashboard

## Project Overview
This project is a Power BI dashboard built using the Superstore dataset to analyze sales, profit, customer segments, shipping performance, and product profitability.

## Objectives
- Analyze sales and profit trends
- Identify top and least profitable products
- Evaluate customer segment performance
- Understand the impact of discounts on profitability
- Generate business insights through visualization

## Tools Used
- Power BI
- Excel / CSV
- Data Visualization
- KPI Analysis

## Dashboard Features

### Executive Overview
- Total Sales KPI
- Total Profit KPI
- Profit Margin
- Order Count
- Monthly Sales & Profit Trend
- Profit by Region
- Top Profitable Sub-Categories
- Sales by Category

### Product & Customer Analysis
- Top 10 Profitable Products
- Least Profitable Products
- Sales by Customer Segment
- Profit by Ship Mode
- Discount Impact on Profit

## Key Insights
- Consumer segment contributed the highest sales
- Standard Class shipping generated the highest profit
- Some products generated negative profits
- Higher discounts reduced profitability in several categories
